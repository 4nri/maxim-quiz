# Тренажёр «Мой героический район»

Подготовка Максима к квизу 19 ноября 2026 года, 13:00–13:30 (Москва).

**Сайт:** https://4nri.github.io/maxim-quiz/

## Возможности

- 18 тем из выданных материалов, включая полные тексты.
- 108 тренировочных вопросов с четырьмя вариантами ответа; 48 вопросов по темам Максима (4–6).
- Карточки, ключевые факты, отметки о чтении и памятки для печати.
- Тренировка без таймера: приоритет получают ошибки и ещё не пройденные вопросы.
- Пробный квиз: 20 уникальных вопросов, 60 секунд на каждый, разбор после завершения. Каждая из 18 тем встречается один раз; два дополнительных вопроса выбираются из тем 4–6. Это правило тренажёра, а не заявленное правило официального квиза.
- Повторение ошибок. Следующий верный ответ убирает вопрос из списка повторения.
- Прогресс и текущий раунд сохраняются в localStorage. Отсчёт текущего вопроса пробного квиза продолжается при уходе со страницы. Следующий вопрос начинается после нажатия кнопки.
- Адаптивная вёрстка, управление ответами клавишами 1–4, поддержка уменьшенного движения.
- На компьютере варианты ответа показаны сеткой 2×2, на телефоне идут одной колонкой. Цвет и символ помогают различать варианты; правильность ответа дополнительно обозначается текстом и значком.
- На телефоне во время квиза закреплён таймер, увеличены области нажатия. Плавная полоска показывает оставшееся время, но сам отсчёт рассчитывается по часам и не зависит от анимации.
- Анимации нажатий, пояснений, карточек и диалогов используют CSS и Web Animations API без библиотек. Клавиатурные действия выполняются без декоративных анимаций; системная настройка уменьшенного движения убирает масштабирование.

## Запуск

Нужны Node.js 22+ для тестов и сборки, Python 3 для локального сервера. Зависимостей npm нет.

```sh
npm run dev
# http://127.0.0.1:4173
npm test
npm run build
```

GitHub Actions запускает тесты, собирает только файлы сайта в `dist/` и публикует их в GitHub Pages после push в `main`. В настройках Pages выбран источник GitHub Actions.

## Материалы и точность

Источники: предоставленные пользователем `КВИЗ.docx` и `Материалы для подготовки к квизу 4–6 классы(1).docx`. Ссылки на 18 статей проекта сохранены в `data.json`. Полные тексты перенесены из первого документа без редакторской правки. Исходные DOCX остаются локально в игнорируемой папке `in/`.

Вопросы созданы для подготовки и не являются официальным банком игры. У каждого вопроса есть пояснение, индекс абзаца и дословный фрагмент, связывающий его с выданным материалом. Сборка банка проверяет наличие фрагмента в соответствующей теме. Это проверка соответствия документу, а не независимая историческая экспертиза его утверждений.

Чтобы обновить материалы из локального DOCX и пересобрать банк:

```sh
python3 scripts/import_sources.py
python3 scripts/build_questions.py
npm test
```

В `scripts/import_sources.py` границы статей заданы по структуре исходного документа. Если структура нового DOCX меняется, сначала нужно обновить границы. Вопросы редактируются в `scripts/questions.txt`; правильный ответ указан первым, интерфейс перемешивает варианты при каждом новом раунде.

## Данные

Сервер, регистрация, аналитика и внешние шрифты не используются. Фамилии участников команды и сообщение из родительского чата не публикуются. Имя Максим используется только для обращения в интерфейсе. Прогресс хранится на устройстве и не синхронизируется между браузерами. Сброс доступен в окне «О тренажёре».

Структура: `app.js` отвечает за интерфейс, `engine.js` за отбор вопросов и прогресс, `data.json` содержит материалы и вопросы. Анимации вынесены в `motion.js` и `motion.css`. Тесты проверяют целостность банка, охват тем в квизе, приоритет повторения, подсчёт результатов, таймер и обработку повреждённого хранилища.

Предоставленные фотографии использованы как ориентир для командного формата и расположения ответов. Фотографии остаются в локальной папке `in/` и не входят в сайт или публичный репозиторий.
